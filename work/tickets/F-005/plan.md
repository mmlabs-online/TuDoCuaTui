## Approach
1. **Install** (lockfile changes): `CI=true npx pnpm@10.34.3 add -D vitest@5.1.0 @vitest/coverage-v8@5.1.0 jsdom@^27`
   (exact same version for vitest and coverage-v8; `vitest@5.1.0` peer range is
   `vite: ^6.4.0 || ^7.0.0 || ^8.0.0`, checked 2026-11-07). If jsdom 27 is not the latest compatible major,
   take the latest major and note it in impl-log. Then confirm a single `vite@8.x` in `pnpm-lock.yaml`
   (`npx pnpm@10.34.3 why vite`). Do not run `pnpm update` or touch other dependencies.
2. **Config**: write `vitest.config.ts` as in the files table (import `defineConfig` from `vitest/config`,
   `react` from `@vitejs/plugin-react`, `path`/`fileURLToPath` for the alias). No `mergeConfig` with
   `vite.config.ts` (R10). Add it to tsconfig `include`. Add `src/test/setup.ts`, scripts, ignores.
3. **Env sanity test** (`src/test/env.test.ts`). If the TZ test fails on Windows outside WSL, fall back to
   `env: TZ: Asia/Ho_Chi_Minh` in the CI job **and** note it in impl-log; do not add `cross-env` without
   recording why.
4. **Extract `filters.ts`** (zero behaviour change, R7):
   - `export const ageInDays = (date: string, now = Date.now()) => date ? Math.floor((now - new Date(date).getTime()) / 86400000) : 999;`
     — same formula as `App.tsx:488`, keeps `new Date(date)` (UTC parse of `YYYY-MM-DD`; T-002 fixes it).
   - `export const STALE_DAYS = 90;` `export const isStale = (i: Pick<Item, "lastWorn">, now = Date.now()) => ageInDays(i.lastWorn, now) >= STALE_DAYS;`
   - `export type ItemFilters = { status: string; season: string; location: string; color: string; special: string };`
   - `export function matchesFilters(i: Item, c: { query: string; category: string; filters: ItemFilters }, now = Date.now())` —
     body copied from `App.tsx:500–509`, the `"Tất cả"` check kept inside, `age(...) >= 90` replaced by `isStale(i, now)`.
   - `export function sortItems(items: Item[], sort: string, now = Date.now())` → `[...items].sort(…)` with the
     comparator copied from `App.tsx:512–521`, `age` → `ageInDays(…, now)`.
   - Imports only `@/types/item` (pure module, no React).
5. **Edit `App.tsx`** exactly as in the files table. Keep `useMemo` deps unchanged. Remove the now-unused
   `let out`. No other edits in the file (F-004 owns the split).
6. **Tests**: write the three test files. Use fixed `now` values (and `vi.useFakeTimers()` only for the local
   repo `wear` tests, since it calls `new Date()` itself). Build fixtures with a small local `makeItem(over)`
   helper per file (no shared fixture module in this slice).
7. **CI**: replace the comment with `- run: pnpm test:coverage` after `- run: pnpm typecheck`.
8. **Checks**: `npx pnpm@10.34.3 typecheck`, `format` then `format:check`, `test`, `test:coverage`, `build`.
   Record outputs (and the coverage table) in `impl-log.md`.
9. Handoff in `ticket.md`: state that AC2 is completed by F-005.2 and list the follow-ups below.
