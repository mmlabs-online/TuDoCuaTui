## Approach
1. **Install** (lockfile only via pnpm):
   `CI=true npx pnpm@10.34.3 add -D @testing-library/react@16.3.3 @testing-library/dom@10.4.2`.
   16.3.3 is the latest RTL and its peers are `react/react-dom ^18 || ^19`, `@testing-library/dom ^10`
   (checked with `npm view` on 2026-11-07); 10.4.2 is the latest `@testing-library/dom`. Confirm
   `npx pnpm@10.34.3 why react` shows only 19.2.x. No other dependency changes.
2. **`src/test/fakeSupabase.ts`** (consult §3 Rec. 3), imports `vi` from `vitest` only:
   - `export type FakeResult = { data?: unknown; error?: unknown }`, `export type Call = { table: string; method: string; args: unknown[] }`.
   - `export function createFakeSupabase(userId: string | null = "user-1")` returns
     `{ client, calls, storage, push(...r: FakeResult[]), pending(): number }`.
   - `client.from(table)` logs `{table, method: "from", args: []}` and returns a builder whose methods
     `select, eq, order, limit, insert, upsert, delete, single, maybeSingle` each log `{table, method, args}`
     and return the builder. The builder has `then(onFulfilled, onRejected)`: it shifts the next result from the
     FIFO (`{ data: r.data ?? null, error: r.error ?? null }`); if the queue is empty it returns a rejected
     promise `Error("fakeSupabase: no scripted result for <table>.<last method>")` so a missing script fails
     loudly. **One queue entry per awaited chain**, in the order chains are awaited (for `Promise.all([list(),
     locations()])`: list first, then locations).
   - `storage = { createSignedUrls, upload, remove, copy }`, each `vi.fn` defaulting to
     `{ data: null, error: null }` (`createSignedUrls` default `{ data: [], error: null }`); `client.storage.from`
     is a `vi.fn` returning `storage`.
   - `client.auth = { getUser: vi.fn(async () => ({ data: { user: userId ? { id: userId } : null }, error: null })), signOut: vi.fn(async () => ({ error: null })) }`.
   - Typed with small local interfaces; no `any`, no cast inside the module.
3. **`repo.supabase.test.ts`**: `vi.mock("./photos", () => ({ resizeImage: vi.fn(), urlToBlob: vi.fn() }))`. In
   `beforeEach`: new fake; `vi.mocked(urlToBlob).mockReset().mockResolvedValue(new Blob(["src"]))`;
   `vi.mocked(resizeImage).mockReset().mockResolvedValue({ blob: resized, width: 800, height: 600 })` (reset
   explicitly; `restoreMocks` does not reset module-mock `vi.fn` state); `vi.spyOn(crypto, "randomUUID")
   .mockReturnValue("00000000-0000-4000-8000-000000000001")` (if jsdom's `crypto` is not spy-able, assert paths
   with `expect.stringMatching(/^user-1\/item-1\/[0-9a-f-]{36}\.jpg$/)` and note it in impl-log).
   `const make = () => createSupabaseRepo(fake.client as unknown as SupabaseClient<Database>)` — the only cast.
   Each test scripts the queue in call order, asserts the result **and** the relevant `fake.calls` entries
   (`toEqual` for the full log in the list/locations/wear tests, `toContainEqual` + order checks elsewhere),
   and ends with `expect(fake.pending()).toBe(0)` where the full path ran. Errors are rejected objects:
   `await expect(p).rejects.toBe(err)`. Wear +1 uses `vi.useFakeTimers({ toFake: ["Date"] })` +
   `vi.setSystemTime(new Date("2026-11-06T17:30:00Z"))`, `vi.useRealTimers()` in `afterEach`; `localToday` is
   real (not mocked), so the test proves the UTC+7 date.
4. **`useWardrobe.test.tsx`**: `const h = vi.hoisted(() => ({ client: null as unknown }))`;
   `vi.mock("@/lib/supabase", async (importOriginal) => ({ ...(await importOriginal<typeof import("@/lib/supabase")>()), get supabase() { return h.client; } }))`
   and `vi.mock("./photos", …)`. `afterEach(cleanup)` from `@testing-library/react` (with `globals: false`
   RTL does not auto-register cleanup) and `h.client = null`. Supabase-mode tests set
   `h.client = fake.client as unknown as SupabaseClient<Database>` (the file's one cast, in a helper) before
   `renderHook`. Use `renderHook(() => useWardrobe(starter, ["Tủ phòng ngủ", "Kệ giày"]))`, `waitFor` for
   load, `act(async () => …)` for mutations. **Fallback** if the getter mock is not honoured by Vitest 5:
   move the Supabase-mode tests to `src/data/useWardrobe.supabase.test.tsx` with a plain
   `vi.mock("@/lib/supabase", …)` whose factory builds the fake via `await import("@/test/fakeSupabase")`, and
   record the extra file in impl-log.
5. **`vitest.config.ts`**: thresholds →

   the aggregate of matching files (Vitest default `perFile: false`); `photos.ts` and `*.test.*` stay excluded

6. **Checks**: `typecheck`, `format` then `format:check`, `test`, `test:coverage`, `build`. Paste the coverage

7. **Handoff** in `ticket.md`: AC status, the coverage numbers, and the follow-ups listed under Split proposal.
